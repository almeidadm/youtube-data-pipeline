# Project Documentation

This directory hosts extended documentation for the YouTube API Collector project.  The
primary `README.md` at the repository root provides a concise overview and quickstart,
but the files in this folder serve as a more traditional “docs” section for users and
contributors.

Files included in this folder:

* `usage.md` – detailed usage instructions, examples and CLI options.
* `architecture.md` – design notes, database schema and pipeline descriptions.
* `development.md` – guidance for developers, running tests and extending the codebase.

Navigate to the individual files for more information.
